# Smart Discharge Home

📄 المحتوى التفصيلي المطور للمشروع (جاهز للإرسال والعرض) إسم المشروع مِداد|MIDAD
عنوان المشروع: 🏠 خروج ذكي → تعافي آمن (Smart Discharge → Home) نظام صحي ذكي لمتابعة وتقييم المريض من المستشفى إلى المنزل
🏥 1. قائمة مهام ما قبل الخروج (Pre-Discharge Assessment Checklist):
تظهر للممرض والمريض داخل المستشفى للتأكد من جاهزية المريض التامة قبل المغادرة:
• توضيح وشرح الخطة العلاجية والتثقيف الصحي: شرح جدول الأدوية، توضيح علامات الخطر (Warning Signs) التي تتطلب مراجعة الطوارئ، وتأكيد مواعيد المتابعة القادمة.
• تقييم قدرة المريض/المرافق (Patient Competency Check): التأكد من قدرة المريض أو مرافقه على التعامل مع الأجهزة الطبية المنزلية أو الغيار على الجروح إن وجد.
• حساب درجة جاهزية الخروج (Smart Discharge Readiness Score): استبيان تفاعلي يتضمن درجات وأسئلة (نعم/لا/جزئي)، ولا تكتمل عملية الخروج في النظام إلا عند تحقيق نسبة جاهزية أمينة (مثلاً 90% فأكثر).
🏠 2. مهام ومتابعة المنزل (Home Post-Discharge Tasks):
تظهر في تطبيق المريض اليومي لضمان الالتزام والدقة:
• تتبع الأدوية (Medication Tracker): قائمة يومية بالأدوية ومواعيدها، مع إمكانية تأكيد تناول الدواء (Taken) أو تحديد سبب عدم التناول.
• تقييم مستوى الألم (Pain Assessment Scale): اختيار رقمي وتفاعلي لشخصية/مقياس الألم (من 0 إلى 10) مع تحديد مكان الألم.
• تقييم الأعراض اليومية (Symptom Assessment Checklist): أسئلة سريعة يومية عن العلامات الحيوية أو الأعراض الجديدة (مثل: الحرارة، الغثيان، ضيق التنفس، تورم الجرح).
• المساعد الصوتي/النصي التفاعلي: يتيح للمريض (خصوصاً كبار السن) تسجيل الأعراض صوتياً أو كتابة في أي وقت خلال اليوم مع إمكانية التعديل والإضافة مرونةً طوال اليوم.
👩🏻‍⚕️ 3. لوحة تحكم الممرض ومتابعة المرضى (Nurse Interactive Dashboard):
• قائمة مرضى متعددة (Multi-Patient List): تظهر للممرض قائمة بجميع المرضى التابعين له بعد الخروج (مثال: المريض أ: صالح العتيبي - جراحة سابقة | المريض ب: نورة الشمري - رعاية باطنية) مع حالة كل مريض (مستقر / يحتاج متابعة / تنبيه عاجل).
• سجل الأيام السابقة عند الضغط على اسم المريض: عند النقر على اسم أي مريض، تفتح صفحة المتابعة الكاملة لجميع الأيام السابقة مفصلة يوماً بيوم (Day 1, Day 2, Day 3...):
 • سجل الأدوية لكل يوم: نسبة الالتزام وأوقات أخذ الدواء.
 • سجل الألم لكل يوم: منحنى تطور الألم على مدار الأيام.
 • سجل الأعراض لكل يوم: التفاصيل والأعراض التي أدخلها المريض صوتياً أو نصياً في ذلك اليوم.
• قسم التحليلات الذكية والتنبيهات (AI Analytics per Patient): تظهر التحليلات والتوصيات عند فتح ملف المريض المحدّد:
 • تحليل المنحنى (Trend Analysis): مقارنة بيانات اليوم بالأيام السابقة تلقائياً بواسطة الذكاء الاصطناعي.
 • التنبيه الذكي الفوري (AI Automated Alert): في حال وجود خلل (مثل: ارتفاع الألم ليومين متتاليين أو تفويت الأدوية)، يُظهر النظام إشعاراً أحمر عاجلاً للممرض لاتخاذ إجراء (اتصال مباشر / طلب مراجعة المستشفى).
